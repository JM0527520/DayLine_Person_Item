# 日序 Dayline

个人工作日程工具，电脑网页版初版。界面使用系统字体和本地资源，可在没有互联网连接时使用。

当前版本：0.2.0。保留原有数据，数据库会自动升级，无需重新建立任务。

界面采用便于阅读的字号：电脑端任务正文 17px，日期与分类等辅助信息 15px，模块标题 20px，表单输入 16px；行高和控件空间同步调整，支持浏览器缩放。浅色与深色均使用轻底色、留白和细分隔划分模块。侧栏及页面滚动条在滚动时显示，闲置后淡出。

点击侧栏和月历的年月，在入口下方的小浮层选择年份、月份，用对勾确认；下方空间不足时显示在入口上方。支持点外部或 Esc 关闭，页面不遮罩。侧栏导航与分类之间的细分隔固定保留，不随中段滚动消失。已完成任务显示绿色对勾，待办保留优先级旗标。设置提供“标准／舒适”显示密度，字号保持一致。导航和设置固定，中间分类与日历独立滚动；刷新后保留页面、月份、选中日期及筛选条件，正式与示例空间分别记忆。

在“设置 → 外观 → 页面主题”中选择跟随系统、浅色或深色，默认跟随系统。主题偏好保存在当前浏览器，同一入口的多个标签页及正式/示例空间共用此偏好；跟随系统时会即时响应电脑外观变化。刷新或重新打开后保留选择，备份恢复不影响主题。浏览器禁止保存时，本页仍可切换并提示无法记住选择。

## 启动

双击项目根目录的 `启动日序.cmd`。启动器会在后台启动本机服务，并尝试打开默认浏览器。

固定访问入口：<http://127.0.0.1:4317>。

若浏览器没有自动打开，手动访问上述入口即可。重复启动会复用已运行的服务。启动器使用本机 Node.js，找不到时会尝试使用当前 Codex 环境已有的 Node.js。当前电脑已具备所需运行环境；迁移到其他电脑需安装 Node.js 20 或更新版本，并保留 `dist`、`scripts` 和启动文件。

## 页面

- 今天：当天任务、之前未完成、定时事项和未来三天内的截止提醒；到期需处理的任务前置展示。首页统计包含今天及过去计划、到期待办，并按任务去重。
- 月度总览：自然周月历，计划和截止分别标记；同一任务两种标记都可打开同一记录。宽屏右侧展示选中日期的完整安排及定时任务总时长。
- 未来任务：后续已安排事项和无计划日期的任务。
- 工作记录：查询所有任务，按分类、状态和日期范围筛选；支持搜索任务名称、备注与分类名称，按日期分组。
- 设置：管理分类、导出和恢复备份、查看上次导出时间、恢复误删任务及返回上次导入前的数据、进入独立示例空间。

每项任务支持标题、备注、三级优先级、可选分类、工作安排与独立的交付截止日期。工作安排明确填写开始日期/时间和结束日期/时间，支持跨日、跨月、跨年；结束的完整日期时间必须晚于开始。只填日期、不填两个时间时为全天安排，包含起止日期；不填日期时为尚未安排。交付截止包含所选日期当天，不决定工作安排的结束时间。状态为待办、进行中、已完成；完成时间自动记录，重新打开后清除完成时间。

首页支持回车快速添加；新建任务继承当前分类。非今日计划的待办可快捷安排到今天或明天，遗留待办可按当前分类批量安排到今天；开始、结束日期一起移动，保留跨度与钟点，交付截止不变。跨日任务在覆盖的每一天显示，安排结束后仍未完成才归入遗留。编辑时检查完整日期时间范围的重叠，提示后仍可保存；全天安排不参与精确时间冲突检查。每日时长只统计该日覆盖的部分，午夜 00:00 结束不占用次日；时长为各事项之和，重叠不作合并，不代表实际投入工时。

例如 10 月 23 日 17:05 至 10 月 24 日 07:56 是有效跨日安排，共 891 分钟；两天分别统计 415 与 476 分钟。没有结束日期的旧任务和旧备份继续按原同日安排读取，无需手动迁移；新版导出为版本 2 备份，支持读取版本 1 和版本 2，新备份请用当前或更新版本恢复。

工作记录按完成日期归档；未完成任务使用计划日期，没有计划日期时使用创建日期。它保存任务当前内容，尚不记录每次修改或每天的进展历史。

## 示例与数据

示例入口：<http://127.0.0.1:4317/?demo=1>。内置 12 条相对当天生成的案例，覆盖定时事项、未来工作、截止、未安排、未完成和已完成记录。可实际编辑，示例数据库与正式数据库相互独立。

任务使用 IndexedDB 保存在当前浏览器的当前用户配置中，不会上传。请持续使用同一浏览器和固定入口。不同浏览器、浏览器配置、端口、`localhost` 与 `127.0.0.1` 各自使用不同的站点存储。Codex 内预览与默认浏览器也可能使用不同的浏览器配置。

在设置中定期导出备份。清除站点数据、使用无痕模式或删除浏览器配置可能使记录丢失。恢复备份会替换当前空间数据，确认前会展示数量，也可先导出当前数据。无效备份会拒绝导入，恢复使用原子事务。

删除任务会移入回收站，可在设置中恢复。原分类不存在时恢复为未分类；存在同编号任务时拒绝覆盖。当前没有永久清理入口。

备份包含当前任务、分类和完成记录，不含回收站、恢复前快照或导出时间。恢复备份前自动保留一份任务与分类快照，可撤销最近一次恢复；再次导入会替换这份快照，撤销会替换导入后的编辑。恢复及撤销均不改变回收站。快照仍在本浏览器中，不能代替外部备份。“上次导出”记录的是发起导出的时间，不能确认用户是否实际保留了下载文件。

离线指断开互联网后，仍可通过本机运行的网页服务使用。关闭全部浏览器窗口后不会提醒；系统通知、重复任务、云端同步与手机端属于后续版本。

## 开发与测试

源码位于 `src/`，已构建网页位于 `dist/`。数据读写集中在 `src/db.ts`，日期、任务规则和备份验证位于 `src/domain.ts`，便于后续增加同步层。

依赖已安装。运行以下命令可重新验证：

```powershell
node node_modules/typescript/bin/tsc -b
node node_modules/vite/bin/vite.js build
node --experimental-strip-types --test tests/domain.test.ts
node scripts/test-e2e.mjs
```

浏览器测试使用当前电脑的 Chrome，端口为 4320，与实际使用入口和数据隔离。换电脑时按实际安装路径调整 `playwright.config.ts`。重新安装依赖可使用 pnpm，并以 `pnpm-lock.yaml` 为准。

图文测试记录见 `TEST_REPORT.md`；完整浏览器报告为 `playwright-report/index.html`。

设计说明见 `DESIGN.md`，独立组件预览为 `design-preview.html`；后续客户体验问题与优先级见 `CUSTOMER_REVIEW.md`。竞品网页访问因自动审批服务 503 未完成，设计说明已标明参考边界。
